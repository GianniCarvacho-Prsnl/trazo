# Trazo v0.1.0 — Primera versión de prueba

Primera versión abierta de Trazo para seleccionar una región de pantalla, anotar y copiar o guardar el resultado. El código propio se distribuye bajo licencia MIT.

## Funciones

- Selección rectangular ajustable dentro de una pantalla.
- Lápiz, resaltador, flechas, líneas, rectángulos, elipses y texto.
- Cinco colores, tres grosores, deshacer y rehacer.
- Copia al portapapeles en PNG/TIFF y guardado PNG.
- Barra de menús, atajo global ⌘⇧2 y modo de prueba del editor.

## Descarga y uso

El archivo `Trazo-v0.1.0-macos-arm64.zip` contiene `Trazo.app` para **Apple Silicon**, con **macOS 14 o posterior**. Descomprime el archivo y abre la app. Pulsa Nueva captura o usa ⌘⇧2; macOS requiere el permiso de Grabación de pantalla para Trazo.

La compilación tiene **firma ad hoc y no está notarizada**. Es una prerelease para pruebas; Gatekeeper puede impedir abrir la descarga. También puedes compilar desde el código fuente con Xcode y Swift 6 siguiendo el README. No se incluye una versión Intel en esta descarga.

El archivo `.sha256` permite verificar la integridad del ZIP:

```sh
shasum -a 256 -c Trazo-v0.1.0-macos-arm64.zip.sha256
```

## Validación y límites

- Ocho pruebas automatizadas correctas para geometría, resolución, composición, PNG e historial.
- Editor y exportación PNG probados visualmente con una imagen sintética.
- Captura real y pegado en aplicaciones externas pendientes de validación completa.
- Región dentro de una sola pantalla; sin selecciones entre monitores.
- Texto de una línea; las marcas no se editan individualmente después de dibujarlas.
- Atajo fijo y salida a disco en PNG.

Las imágenes se procesan localmente. No hay cuentas, subidas, búsqueda web ni impresión.
